Common questions

Know what you’re running.

Is the terminal hosted or installed?

The terminal is a static web app. Open it in a modern browser, pair the device with your Spark Server, and it stores that terminal credential locally.

Does Spark hold merchant funds?

No. Cryptocurrency invoices point to merchant-controlled wallets or nodes. Card charges use the merchant’s connected Stripe account.

Can one server support multiple terminals?

Yes. Create separate clients for counters or devices, then configure payment-method availability per client.

Can developers integrate without this terminal?

Yes. Spark includes authenticated invoice APIs, public checkout endpoints, webhooks, and a JavaScript SDK for custom systems.
